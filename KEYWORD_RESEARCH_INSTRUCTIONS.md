# How To Use Keyword Research

## Quick start

1. Open `Keyword Research`.
2. In the search box, type your main keyword.
   Example: `ai agency`
3. Choose the `Country`.
   Example: `GB`
4. Click `Search`.

After that, the tool will generate keyword ideas and sort them for you.

## Best settings to start with

Use these first:

- `Deep autocomplete scan`: ON
- `Target Count`: `1000`
- `SERP Enrichment Top N`: `5`
- `Include Google Trends overlay`: ON

## Filters

### Include Terms

Put words that must appear in the keyword.

Example:

`ai, agency`

### Exclude Terms

Put words you do not want.

Example:

`jobs, salary, course`

### Modifier Filter

Use this if you want special keyword types.

Examples:

- `best`
- `pricing`
- `vs`
- `near me`

### Intent Filters

You can keep only:

- `Informational`
- `Commercial`
- `Transactional`
- `Local`
- `Navigational`

## Local SEO

If you want city keywords, fill these:

### Local SEO Cities

Example:

`London, Manchester, Leeds`

### Local SEO Services

Example:

`AI agency, SEO consultant`

This helps generate keywords like:

- `ai agency london`
- `seo consultant in manchester`

## Competitor gap

If you want to compare against competitors:

### Competitor Domains

Example:

`competitor1.com, competitor2.co.uk`

### Target Domain

Example:

`yourdomain.com`

Then the tool will show keywords where competitors appear but your site does not.

## What the sections mean

### Top Opportunities

These are the best keywords first.

They include:

- priority score
- opportunity score
- difficulty estimate
- trend
- page recommendation

Use this section first.

### Intent Clusters and Page Targets

This groups keywords that should usually go on the same page.

Use it to decide:

- what should be one page
- what should be separate pages
- what content type to create

### Content Brief

Inside each cluster, you get:

- title ideas
- H2 ideas
- FAQs
- internal links

Use this when writing content.

### All Scored Keywords

This is the full keyword list.

Use it when you want to:

- inspect all results
- save keywords
- export CSV
- track keywords

## Saved Lists

You can create lists like:

- `Money pages`
- `Blog ideas`
- `Low competition`
- `Client A`

How to use:

1. Create a list
2. Select the list
3. Click `Save to list` on keywords or clusters

## AI Filter

Use this after the search if you want only the closest keywords.

Example prompt:

`Keep only keywords from people who want to hire an AI agency. Remove educational and weak intent keywords.`

Then click:

`Filter with AI`

## Export

Click:

`Export CSV`

This downloads the current results with columns like:

- keyword
- intent
- cluster
- priority score
- opportunity score
- recommended page type
- notes

## Recommended workflow

For a normal project, use this order:

1. Search the seed keyword
2. Choose country
3. Add include/exclude filters
4. Enable SERP enrichment
5. Enable trends
6. Check `Top Opportunities`
7. Check `Intent Clusters and Page Targets`
8. Save good keywords to lists
9. Export CSV
10. Track final keywords

## Easy example

If you want to research `ai agency` in the UK:

Use:

- Keyword: `ai agency`
- Country: `GB`
- Include Terms: `ai, agency`
- Exclude Terms: `jobs, course, salary`
- SERP Enrichment Top N: `5`
- Trends: `ON`

Then:

- save transactional keywords to `Money pages`
- save informational keywords to `Blog ideas`
- export the final keyword set
